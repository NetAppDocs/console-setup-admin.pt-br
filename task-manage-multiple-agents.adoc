= Visualizar sistemas associados a diferentes agentes do Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Se sua organização utiliza vários agentes do Console, você pode alternar entre eles para visualizar os sistemas associados a um agente específico.

Para usuários com a função de administrador da organização, isso é útil ao implementar sua estratégia de gerenciamento de recursos. Você pode alternar para um agente diferente ao descobrir sistemas de storage para associar automaticamente esses sistemas ao agente que está no mesmo ambiente.

Para administradores de storage, alterne entre agentes para gerenciar os sistemas associados a cada agente.

Por exemplo, em um ambiente multicloud, sua organização pode ter um agente na AWS e outro no Google Cloud. Alterne entre esses agentes para gerenciar os sistemas Cloud Volumes ONTAP nos respectivos ambientes de nuvem.


NOTE: Essa opção não está disponível ao visualizar o NetApp Console a partir da interface de usuário local do agente.

.Etapa
. Selecione *Armazenamento* > *Gerenciamento* > *Sistemas*.
. Selecione o ícone de agentes do Console (image:icon-agent.png["ícone do agente"] ) no canto superior direito para visualizar a lista de agentes disponíveis.
+
image:screenshot-connector-switch.png["Uma captura de tela que mostra o ícone Agentes no cabeçalho e a ação Alternar."]



.Resultado
O Console é atualizado e mostra os sistemas associados ao agente selecionado.
