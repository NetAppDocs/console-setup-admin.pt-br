= Fluxo de trabalho de primeiros passos para o NetApp Console no modo privado
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Você pode instalar o NetApp Console localmente ou em um ambiente de nuvem seguro. O modo privado é normalmente usado em ambientes locais que não possuem conexão com a internet e em regiões de nuvem seguras, que incluem  https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] e  https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"] link:task-prepare-private-mode.html["Preparar para implantação"]
[role="quick-margin-list"]
. Prepare um host Linux dedicado que atenda aos requisitos de CPU, RAM, espaço em disco, ferramenta de orquestração de contêineres e muito mais.
. Configure a rede que fornece acesso às redes de destino.
. Para implantações em nuvem, configure permissões no seu provedor de nuvem para que você possa associar essas permissões ao agente do Console após instalar o software.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"] link:task-install-private-mode.html["Implantar o agente do Console"]
[role="quick-margin-list"]
. Instale o agente do Console em seu próprio host Linux.
. Configure o NetApp Console abrindo um navegador da web e digitando o endereço IP do host Linux.
. Para implantações na nuvem, conceda ao NetApp Console as permissões que você configurou anteriormente.

== Recursos e serviços compatíveis para o NetApp Console no modo privado

A tabela a seguir lista os recursos de gerenciamento de storage, serviços de dados e recursos administrativos disponíveis no NetApp Console quando você o instala no modo privado. Os recursos variam quando você instala o NetApp Console na nuvem em comparação com suas instalações.

=== Modo privado instalado na nuvem

| Área de produtos | NetApp service ou recurso | Agente do Console necessário 


.2+| *Gerenciamento de sistemas de armazenamento* Esta parte da tabela lista o suporte para gerenciamento de sistemas de armazenamento a partir do NetApp Console. Ela não indica os destinos de backup suportados para NetApp Backup and Recovery. | Cloud Volumes ONTAP | Sim, mas como não há acesso à internet, os seguintes recursos não estão disponíveis: atualizações automáticas de software e AutoSupport. 


 a| 
Clusters ONTAP locais

* Requer conectividade da nuvem (onde o agente do NetApp Console está instalado) para o ambiente local.
+
Você precisa ter um agente do NetApp Console instalado para descobrir clusters ONTAP locais.


| Você pode usar a descoberta direta sem um agente do Console, mas precisa de um agente para usar os recursos de gerenciamento. 


.3+| *Serviços de Dados*  a| 
Backup and Recovery

* No modo privado, NetApp Backup and Recovery suporta apenas backup e restauração de dados de volume ONTAP. https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-journey.html#support-for-sites-with-no-internet-connectivity["Veja a lista de destinos de backup suportados para dados ONTAP"^] Não há suporte para backup e restauração de dados de aplicativos e dados de máquina virtual.
* Não é compatível no Google Cloud ou em https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^], https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] ou https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^]

| Sim 


 a| 
Classificação da NetApp

* As únicas fontes de dados suportadas são aquelas que você pode descobrir localmente. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#supported-data-sources["Veja as fontes que você pode descobrir localmente"^]
* Funcionalidades que exigem acesso à internet de saída não são suportadas. https://docs.netapp.com/us-en/data-services-data-classification/task-deploy-compliance-dark-site.html#limitations["Veja as limitações do recurso"^]

| Sim 


| NetApp Replication | Sim* (não é necessário se a replicação for de ONTAP local para ONTAP local) 


| *NetApp recursos do contrato de suporte* | Nenhum | -- 


.6+| *Funcionalidades administrativas* | Auditoria | Não

Licenses and subscriptions gerenciamento de licenças e assinaturas

* Apenas BYOL é suportado com o modo privado.
+
Para Cloud Volumes ONTAP BYOL, somente o licenciamento baseado em nós é suportado. O licenciamento baseado em capacidade não é suportado. Como não há conexão de internet disponível, você precisa fazer o upload manual do seu arquivo de licenciamento do Cloud Volumes ONTAP no Console.



https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-manage-node-licenses.html#add-unassigned-licenses["Saiba como adicionar licenças"^]
