Os endpoints listados na opção 1 são recomendados por serem mais seguros. Recomendamos que você configure seu firewall para permitir os endpoints listados na opção 1, enquanto bloqueia os endpoints listados na opção 2. Observe o seguinte sobre esses endpoints: ** Os endpoints listados na opção 1 são compatíveis a partir da versão 3.9.47 do agente do Console. Não há compatibilidade retroativa com versões anteriores do agente do Console. ** O agente do Console contata primeiro os endpoints listados na opção 2. Se esses endpoints não estiverem acessíveis, o agente do Console contata automaticamente os endpoints listados na opção 1. ** Os endpoints da opção 1 não são compatíveis se você usar o agente do Console com NetApp Backup and Recovery ou NetApp Ransomware Resilience. Nesse caso, você pode bloquear os endpoints listados na opção 1, enquanto permite os endpoints listados na opção 2.

O host pode tentar atualizar os pacotes do sistema operacional durante a instalação.  O host pode entrar em contato com diferentes sites de espelhamento para esses pacotes de sistema operacional.
