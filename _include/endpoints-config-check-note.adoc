* Para novas implantações de agentes, NetApp verifica os seguintes endpoints: link:reference-networking-saas-console.html["listados aqui"^]. Essa verificação de configuração falha com um erro se você estiver usando os endpoints anteriores utilizados para atualizações, link:reference-networking-saas-console-previous.html["listados aqui"]. NetApp recomenda atualizar suas regras de firewall para permitir o acesso aos endpoints atuais e bloquear o acesso aos endpoints anteriores o mais breve possível. link:reference-networking-saas-console-previous.html#update-endpoint-list["Aprenda a atualizar sua rede"].
* Se você atualizar os endpoints no seu firewall, seus agentes existentes continuarão funcionando.
