= Funções de acesso do Cloud Volumes ONTAP no NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Você pode atribuir as seguintes funções aos usuários para conceder-lhes acesso ao Cloud Volumes ONTAP no NetApp Console.

* *Cloud Volumes ONTAP admin*: fornece acesso completo a todas as operações do Cloud Volumes ONTAP.
* *O operador do Cloud Volumes ONTAP*: executa operações importantes de armazenamento, como descobrir e gerenciar sistemas Cloud Volumes ONTAP, incluindo adicionar volumes, agregados, snapshots e replicações, modificar algumas configurações e atualizar versões do Cloud Volumes ONTAP.
* *Cloud Volumes ONTAP viewer*: Fornece acesso somente leitura às informações do Cloud Volumes ONTAP. Esta função não pode executar nenhuma operação ativa. Algumas abas e telas que contêm informações de configuração podem não estar disponíveis para visualizadores.


link:reference-iam-predefined-roles.html["Saiba mais sobre funções de acesso"] .

Atribua funções do Cloud Volumes ONTAP no nível da organização, pasta ou projeto que contém o sistema. As funções da plataforma permitem que os usuários administrem os recursos do NetApp Console, enquanto as funções do Cloud Volumes ONTAP permitem que os usuários gerenciem os sistemas Cloud Volumes ONTAP. Para obter orientações sobre o planejamento da atribuição de funções, consulte link:task-cvo-rbac-setup.html#plan-cloud-volumes-ontap-role-assignments["Configure o acesso baseado em funções para Cloud Volumes ONTAP"].



[[role-migrations-for-existing-users]]
== Migrações de funções para usuários existentes

Ao atualizar um agente do Console para a versão 4.9.0 ou posterior, o Console atribui funções adicionais do Cloud Volumes ONTAP aos usuários existentes com base em suas funções na plataforma.


NOTE: Quando um agente do Console existente é atualizado para o Console 4.9.0 ou posterior, o Console executa um processo de inicialização único que atribui funções do Cloud Volumes ONTAP aos usuários existentes na organização. Esse processo pode levar até 30 minutos para ser concluído. Para revisar e ajustar as funções inicializadas, consulte link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["Analise as funções após atualizar o agente do NetApp Console"].

Os mapeamentos a seguir se aplicam somente a este processo de migração único.

[cols="50,50"]
|===
| Função existente na plataforma | Função do Cloud Volumes ONTAP atribuída durante a inicialização 


| Superadministrador | Administrador do Cloud Volumes ONTAP 


| Administrador da organização | Administrador do Cloud Volumes ONTAP 


| Administrador da Federação | Administrador do Cloud Volumes ONTAP 


| Administrador de pasta ou projeto | Administrador do Cloud Volumes ONTAP 


| Super visualizador | Visualizador do Cloud Volumes ONTAP 


| Visualizador de organização | Visualizador do Cloud Volumes ONTAP 


| Visualizador da Federação | Visualizador do Cloud Volumes ONTAP 


| Visualizador de pastas ou projetos | Visualizador do Cloud Volumes ONTAP 


| Qualquer outra função na plataforma | Visualizador do Cloud Volumes ONTAP 
|===
O NetApp Console atribui a função Cloud Volumes ONTAP no mesmo nível hierárquico da função de plataforma existente. Esses mapeamentos não se aplicam a novas atribuições de função. Para revisar e ajustar as funções predefinidas, consulte link:task-cvo-rbac-setup.html#review-roles-after-upgrading-the-console-agent["Analise as funções após atualizar o agente do NetApp Console"].


NOTE: Um problema conhecido atualmente impede que a combinação das funções *Visualizador da organização* e *Visualizador do Cloud Volumes ONTAP* funcione no escopo da organização. Use a função *Administrador da organização* ou *Administrador de pasta ou projeto* como solução alternativa temporária.



[[how-role-changes-take-effect]]
== Como as mudanças de função entram em vigor

Aguarde até uma hora para que as atribuições de função novas ou atualizadas entrem em vigor. O Cloud Volumes ONTAP atualiza as atribuições de função a cada hora.
